# 发票 A4 排版打印

Chrome 浏览器插件。上传发票、行程单或付款截图，统一缩放后排到 A4 页面中打印，适合报销材料整理和批量打印。

## 功能

- 支持上传 PDF、PNG、JPG/JPEG、WEBP。
- 支持多文件上传和拖拽上传。
- 支持 A4 横向、纵向打印。
- 支持自动排版，以及每页 1、2、4、6 张手动排版。
- 支持页面边距、发票间距、整体缩放调节。
- 支持显示票据框边界和发票间裁剪线。
- 付款截图等手机长图会在自动模式下按横向 A4 密集排版。
- 所有处理在浏览器本地完成，不上传任何数据。

## 安装

1. Chrome 打开 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本项目目录
4. 工具栏出现插件图标，点击即在新标签页打开工具

## 使用

点击工具栏插件图标，打开工具页后：
1. 上传发票 PDF 或图片（支持多选和拖拽）
2. 左侧面板调整排版参数
3. 点击「打印」按钮，在打印窗口中关闭页眉页脚、缩放设为 100% 即可
